# FEM Modeler

ブラウザで**部材の形状・構成を生成するモデリングアプリ**です。形状を作り、配置・複製・グループ化し、材質名や断面寸法を付けて別アプリへ渡します。解析条件の設定、メッシュ生成、ソルバ実行、解析結果の表示は現在の製品範囲に含めません。

> 公開サイトは最後にデプロイされた版です。このリポジトリの変更は、デプロイするまで公開サイトへ反映されません。

## 作成できるモデル

- 直方体、円柱、パイプ、平板、穴あき平板、L形ブラケット、フレーム、トラス、流路形状の9種類。
- 寸法再編集、移動・回転・拡大縮小、複数ボディのパターン複製、表示切替、Undo/Redo。
- ボディ・面・辺・頂点の名前付きグループと、座標・面法線による構成員編集。
- 任意の材質名・密度・メモ、断面形状・寸法と部材への割当。解析用の弾性・熱・流体物性は設定しません。
- 空モデル、フレーム、トラス、板、パイプ、L形ブラケットの開始テンプレート。荷重・支持・解析ケースは作成しません。
- STEP/IGES/STLの形状読込、単位を保持した保存、自動保存と世代復元、日本語/英語、狭幅レイアウト。

モデル確認は形状・配置・構成参照の整合性を検査します。強度、安全性、解析の成立性を判定する機能ではありません。

## 別アプリへの受け渡し

| 形式 | 用途・保持する情報 |
|---|---|
| STEP / IGES | 全ボディのCAD形状と配置。native形状または取り込んだCAD原本の曲面を使用 |
| `.fem.json` | 編集可能なモデル、構成、材質、断面、割当、単位、識別ID、形状資産の保存 |
| `.fem.zip`（Bundle） | JSONと形状資産をまとめた可搬保存。読込時にハッシュと参照を検査 |

STEP/IGESはJSONの材質・断面・グループ情報をすべて転送する形式ではありません。フレーム・トラスは**部材中心線**を出力し、断面付きソリッドへ押し出す機能はありません。構成情報を渡す場合はJSON/Bundleも使用してください。STLのみの形状から厳密なSTEP/IGES曲面を復元することはできません。詳細は[CAD対応範囲](docs/cad-formats.md)を参照してください。

旧版の解析情報を含むプロジェクトも読み込めます。読込だけで情報を破棄せず、JSON/Bundleで保存できますが、解析画面やソルバ出力は提供しません。構成要素を削除した場合の参照整理は従来どおり行います。旧版の解析用ライブラリとその互換テストは移行用として一部ソースに残っています。

## 開発・実行

Node.js 20.19以上、または22.12以上とnpmを使用します。

```bash
npm ci
npm run dev
```

`http://localhost:5173/FEM-Modeler/` を開きます。実行中のアプリはブラウザ内で動作し、モデルを外部サービスへ送信しません。CADエンジンは初回操作時に約66 MB取得します。

```bash
npm run typecheck
npm run lint
npm run test
npm run test:coverage
npm run audit
npm run build
npm run bundle:check
npm run preview
```

残している旧生成スクリプトの互換テストには、事前に `uv sync --locked --project solver-tests/openfoam` を実行してください。通常のモデリング操作・ビルド・CAD受け渡しに解析ソルバやDockerは必要ありません。

ブラウザ試験は `npx playwright install chromium` の後に `npm run test:e2e` を実行します。性能測定は任意の `npm run test:performance` です。詳細は[ブラウザ試験](tests/e2e/README.md)と[性能測定](tests/performance/README.md)を参照してください。

## 保存と互換性

正本は共通JSONモデルです。自動保存はIndexedDBでプロジェクト別・世代別に管理し、別タブとの競合や保存失敗時は現在の編集内容を保護します。Undoは最大100操作・推定64 MiB、自動保存はプロジェクトごとに最大5世代、ブラウザ内全体で128 MiBです。大きな資産を削除する前にファイル保存してください。

旧ファイルとの互換性のため、JSONスキーマには解析関連の予約フィールドが残ります。新しいモデリングプロジェクトでは解析データを生成せず、ソルバ設定は無効です。
