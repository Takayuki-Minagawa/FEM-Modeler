FEM Modeler distributes the package's opencascade.wasm.js and
opencascade.wasm.wasm unchanged, as separate ES-module and WASM files.
The application source and integration code are available at:
https://github.com/Takayuki-Minagawa/FEM-Modeler

To use a modified library, build it with the upstream binding generator and
Docker/Emscripten instructions, retaining the used API signatures. Replace
node_modules/opencascade.js/dist/opencascade.wasm.js and
node_modules/opencascade.js/dist/opencascade.wasm.wasm, then run npm run build.
The build copies these replaceable files to assets/cad-occt-1.1.1/.
No signing or integrity enforcement prevents local library replacement.
Modifications and reverse engineering of this library for debugging such
modifications are permitted under the LGPL.
