# モデリング専用への再構成

2026-10-18（日本時間）。ユーザーの訂正により、製品の目的を「部材の形状・構成を生成し、別アプリへ渡すこと」に変更した。前の追加要望に含まれた解析関連の拡張計画より、この訂正を優先する。受け渡し形式はSTEP/IGESとJSON/Bundleで確認済み。

## 作業方針

1. 変更前のソースと差分をリポジトリ外へ退避。
2. 新規モデル・テンプレート・画面・モデル確認・出力をモデリング専用へ変更。
3. 解析用のフォーム、サンプル集、結果表示・比較・収束性・実メッシュの追加UIを撤去。
4. 旧プロジェクトの形状・構成と未編集データの保存互換性を維持。
5. 目的が変わったUI試験を現行の操作へ置換し、保存・精度・Undo・CAD・競合保護は引き続き検証。

## 現在の機能範囲

| 残すもの | 整理したもの |
|---|---|
| 9形状の生成・寸法再編集・変換・複製 | 荷重、拘束、解析ケースの作成画面 |
| 名前付きグループと条件による構成員編集 | メッシュ推定、実メッシュ生成・取込 |
| 任意の材質名・密度・メモ、断面形状・寸法・割当 | 弾性・熱・流体物性の入力、計算用断面諸量の手動編集 |
| 形状・構成参照のモデル確認 | ソルバ向けの適合性・物理量・成立性検証 |
| CAD/STL読込、STEP/IGES、JSON/Bundle | ソルバZIP、解析条件CSV、解析レポート、結果取込/比較/コンター/変形/GCI |
| 保存、復元、Undo/Redo、単位、狭幅操作 | 解析ベンチマークのテンプレートと検証済み結果サンプル集 |

新規テンプレートは形状と構成グループを作成する。フレームは柱/梁、トラスは上弦材/下弦材/腹材のグループを持つ。支持点や荷重を自動で追加しない。

## 保存と受け渡しの境界

- JSON/Bundleは編集可能な構成情報を保持する。旧プロジェクトの解析情報も読込だけで破棄しない。旧解析パネルを記録したファイルを開いても、画面はモデリング用パネルへ戻す。
- 新規JSONも旧スキーマ互換の予約フィールドを持つが、荷重・拘束・解析ケース・結果は空で、ソルバ設定は無効。旧ソルバライブラリ/独立した互換テストは一部ソースに残るが、現在のUIから実行・出力できない。
- 材料や断面の旧解析物性は、名称・密度・寸法等を編集しても不要に消去しない。形状やグループ削除に伴う参照修復は継続する。
- STEP/IGESは複数ボディのCAD形状と配置を出力する。材質・断面割当・グループの完全転送はJSON/Bundleを用いる。
- フレーム/トラスのCAD出力は中心線であり、断面付きソリッド生成ではない。STLから厳密なCAD曲面への変換も対象外。
- モデル確認は幾何と構成の整合性を検査する。強度・安全率・解析の成立性を保証しない。
